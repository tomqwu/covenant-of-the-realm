# Covenant of the Realm

**Covenant of the Realm**（中文工作名：**《山河有契》**）是一个原创、多人在线、持续演化的修仙 MUD 项目。

项目目标不是改编任何既有小说，而是构建一套完整的修仙世界：从凡俗社会、灵气生态、修炼境界和修仙百艺，到宗门政治、玩家经济、跨界探索、飞升、传承与服务器历史。

## Status

Pre-production / world and systems design.

The current design study is exploratory. The next major deliverable is a complete cultivation world and multiplayer MUD bible v0.2.
