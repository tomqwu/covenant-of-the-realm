# 《山河有契》美术方向合同 v0.1

状态：已确认第一阶段方向

适用范围：照禾县 90 分钟垂直切片

## 1. 一句话方向

以「像素行旅」承担可玩世界，以「纸上山河」承担人物情感与材质气质，以
「叠景秘境」承担少数境界转折；三者共享同一套克制、凡俗、危险而有诗意的
视觉世界。

## 2. 三层视觉语言

### 常规游戏层 · 像素行旅

- 城镇、野外、洞窟、移动、战斗、交互热点与所有常规动画使用手绘像素；
- 采用俯视三分之四视角，角色目标高度 48–64 px，最终基准由移动原型验证；
- 使用清晰像素簇、有限色盘和硬边缘，不使用纹理过滤与伪景深；
- 环境可以丰富，但人物、敌人、出口、可拾取物和危险区域必须一眼可辨；
- 水、雾、光和灵力效果不得覆盖碰撞、受击或行动反馈。

### 叙事表现层 · 纸上山河

- 对话肖像、章节插画、关键过场和图鉴采用工笔精度与矿物色水墨质感；
- 角色服装、发型、道具和色彩必须与像素形态共享同一结构设计；
- UI 可以使用低对比纸纤维、干笔边缘与墨线，但纹理不能影响文字可读性；
- 立绘表现人情和身体状态，不把所有角色美化成无瑕仙人。

### 特殊转折层 · 叠景秘境

- 仅用于境界突破、梦境、重大秘境显现与极少数章节高潮；
- 使用纸雕层片、克制低模、水墨材质、雾和柔金体积光；
- 进入特殊表现时仍保留常规交互遮罩、导航和战斗轮廓；
- 不为普通地图维护第二套完整 2.5D 内容管线。

## 3. 色彩与材质

| 用途 | 工作色 | 说明 |
| --- | --- | --- |
| 墨色 | `#1F2523` | 轮廓、深部结构，不使用纯黑压死细节 |
| 河岩 | `#3F5555` | 水、石与阴影的冷中性色 |
| 褪靛 | `#415268` | 主角识别色 |
| 草青 | `#829582` | 植被、药材与砚青辅助色 |
| 药赭 | `#9A5E42` | 砚青识别色、木材与生活温度 |
| 纸白 | `#D8CBB0` | UI、雾和留白，不使用刺眼纯白 |
| 灵金 | `#D5B56B` | 唯一常驻法术强调色，严格限量 |

不同地区可以偏移明度与温度，但不应随意增加新的高饱和强调色。木、麻、石、
旧纸、铜与草药是第一章的主要材质；丝绸、玉石和大面积金属属于稀缺物。

## 4. 角色结构

### 主角 · 工作设定

- 年轻凡人行旅，深色实用半髻；
- 炭黑麻衣、褪靛内层、旧蓑衣和采药袋；
- 轮廓重心低、装备有限，不携带巨型武器或贵重装饰；
- 当前男性外形是垂直切片工作设定，不排除后续角色创建方案。

### 砚青 · 工作设定

- 年轻女药师，神态冷静、观察多于表演；
- 赭红与草青分层工装、束袖、皮药箱；
- 道具体现分类、包扎和采集，不使用珠宝与宫装建立身份；
- 像素形态、肖像和过场必须保持脸型、发髻、肩线与药箱一致。

## 5. 灵力和战斗反馈

- 常规灵力是一条短、细、方向明确的柔金气线；
- 符箓必须保留纸张、墨纹和贴附目标的物理感；
- 命中依赖轮廓、位移、短帧停顿和材质反应，不依赖全屏闪光；
- 岩甲兽以重量、甲片缝隙和低姿态建立威胁，不设计成人形石魔；
- 战斗背景的明度和纹理必须让敌我轮廓保持足够对比。

## 6. 禁区

- 不复制外部小说或游戏的人物、服装、法宝、场景、构图与 UI；
- 不使用悬浮宫装、巨剑、霓虹仙气、无来源的奢华仙宫和泛二次元脸；
- 不用平滑插值、景深、辉光和大量粒子掩盖像素资产不足；
- 不把生成概念图直接切割成正式角色、贴图或营销资产；
- 不在未验证成本前让 C 层成为普通地图的默认管线。

## 7. 第一轮生产验证

1. 主角与砚青：肖像、正侧背结构和像素游戏形态；
2. 照禾渡口：无 UI 环境关键帧与实际游戏镜头；
3. 藏泉山道：移动、预警、岩甲兽战斗与撤退轮廓；
4. 藏泉石室：常规像素探索到叠景突破的转换；
5. 带真实中文 UI 的 16:9 探索和战斗画面。
