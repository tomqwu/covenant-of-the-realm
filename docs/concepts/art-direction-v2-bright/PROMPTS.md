# v2 明亮基线提示词记录

生成日期：2026-08-01

工具：Codex 内置 OpenAI ImageGen

输入：五张 v1 项目内部概念图分别作为唯一编辑目标。没有输入外部小说插图、
游戏截图、艺术家作品或第三方素材。所有输出都是非破坏性同构图变体。

## 共同修改要求

只调整光照、天气、色阶、空气与人物情绪；保留角色身份、服装和道具结构、像素
比例、图板布局、地图几何、战斗站位、敌人结构与特殊叠景层次。以暖纸、河玉、
晴靛、新青、暖赭和受控灵金建立清透春日感。禁止霓虹、糖果色、过曝、Bloom、
塑料动漫皮肤、萌化敌人、宫装和新增文字或 UI。

## 主角标准板

对 v1 主角图执行 identity-preserve 编辑。纸底从灰米色提升为干净暖象牙色；保留
炭黑与褪靛但提高中间调，草、皮革、肤色和蓑草加入温暖日光。完整保留同一张脸、
半髻、身体比例、蓑衣、药袋、正侧背、肖像、装备研究和所有像素动作。表情只允许
更松弛、精神，不增加道具、文字或标签。

## 砚青标准板

对 v1 砚青图执行 identity-preserve 编辑。纸底改为暖象牙色，赭红与草青成为明亮
但不糖果化的矿物色，皮革、药草和肤色进入温暖日光。完整保留同一张脸、发髻、
比例、束袖、药箱、工具、正侧背、肖像、像素动作和岩甲兽比例参照。只让神态更
亲近，不重设计服装或人物。

## 照禾渡口

对 v1 地图执行 lighting-weather 编辑，从阴天暮色改为小雨后通透的春日上午。
河水使用浅蓝绿和硬边闪点，植被为新青，石路更清洁，木、陶和布保留暖赭；远雾
变薄，并以少量野花、菜畦、晾晒和既有村民活动增加生活气。完整保留镜头、地形、
道路、出口、码头、船、房屋、工场、药田、洞口和人物位置，不新增建筑。

## 藏泉山道战斗

对 v1 战斗图执行 lighting-weather 编辑，改为清朗山地早晨与冷色瀑布水汽。
提高石路、植被和人物中间调，保留冷青接触阴影和洞口深值；灵金仍只标记符纸、
敌人弱点与方向关系。完整保留镜头、路径、退路、洞穴、瀑布、两名角色、岩甲兽、
动作和间距。危险感来自重量、姿态与战术关系，不依赖黑暗。

## 藏泉突破

对 v1 特殊场景执行 lighting-weather 编辑，改为雨后日出、珍珠色空气、清泉与
安静的新生感。使用暖纸光、河玉远山、少量晨桃和单一灵金脉络；洞穴前景仍是冷色
取景框。完整保留构图、纸雕层山河、人物尺度、主角打坐、砚青守望、石灯、瀑布和
能量关系，不增加神像、宫殿、人物或爆炸光效。

## 使用边界

这些输出只用于色彩、氛围和生产规格讨论。正式 Sprite、Tile、肖像、贴图和宣传
资产必须单独绘制，并完成相似性、许可、引擎可读性和性能检查。
